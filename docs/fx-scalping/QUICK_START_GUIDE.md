# FX 5分足スキャルピングEA クイックスタートガイド

## 🚀 10分で始める自動売買

### ステップ1: インストール（3分）

1. **ファイルをダウンロード**
   - GitHubから最新版をダウンロード
   - ZIPファイルを解凍

2. **MT4にコピー**
   ```
   MT4 → ファイル → データフォルダを開く
   → MQL4フォルダに以下をコピー：
     - Experts/FX5MinScalpingEA.mq4
     - Include/FX5MinScalping/（フォルダごと）
   ```

3. **MT4を再起動**

---

### ステップ2: 初回セットアップ（5分）

1. **チャート準備**
   - EUR/USD の5分足チャートを開く
   - チャートを整理（不要なインジケーター削除）

2. **EA適用**
   - ナビゲーターから「FX5MinScalpingEA」をドラッグ
   - 設定画面が開く

3. **必須設定のみ変更**
   ```
   ✅ 自動売買を許可する
   
   DefaultLots: 0.01（最小から開始）
   MaxTradesPerDay: 3（安全重視）
   MaxDailyLoss: 3.0（3%で停止）
   ```

4. **自動売買を有効化**
   - ツールバーの「自動売買」ボタンをクリック
   - ニコちゃんマークが笑顔になればOK

---

### ステップ3: 動作確認（2分）

#### ✅ 正常動作のサイン
- チャート左上に情報パネル表示
- エキスパートタブに「EA Initialized」メッセージ
- Status: Active 表示

#### ❌ 問題がある場合
- エキスパートタブでエラー確認
- 自動売買ボタンが押されているか確認
- 証拠金が十分か確認（最低$100）

## 📊 トレード戦略の簡単理解

### 🔵 パターンブレイク（基本）
```
相場が「もみ合い」→「突破」したらエントリー

[図解]
━━━━━┓ ← 突破でエントリー
□□□□┃   （レンジを上抜け）
━━━━┛
```
**いつ使う？**: トレンドの始まりを捉えたい時

### 🟢 プルバック（安全）
```
一度突破 → 戻ってきて → 再上昇でエントリー

[図解]
    ╱← 再上昇でエントリー
  ╲╱ ← 一時的な戻り
  ╱
━━━
```
**いつ使う？**: より確実なエントリーをしたい時

### 🔴 コンボ（強力）
```
2段階のもみ合い → 最終突破でエントリー

[図解]
      ┏━┓╱← 強い上昇
    ┏━┛ ┗━ ← 第2もみ合い
  ╱┗━━━━  ← 第1もみ合い
━━━
```
**いつ使う？**: 強いトレンドを狙いたい時

## 💡 成功のコツ

### ✅ やるべきこと
1. **小さく始める**: 0.01ロットから
2. **記録を取る**: 毎日の結果をメモ
3. **時間を守る**: 推奨時間帯のみ取引
4. **ルールを守る**: 損切りは絶対

### ❌ やってはいけないこと
1. **ロットを急に上げる**: 段階的に増やす
2. **負けを取り返そうとする**: 冷静に
3. **24時間動かす**: 良い時間帯のみ
4. **パラメータを頻繁に変える**: 1週間は固定

**Q: トレードが始まらない**
A: 
- 自動売買ボタンON？
- 時間は16:00-24:00？

- StopLossを12-15pipsに

- ロット数は変えない

### エラー対処

| エラー | 原因 | 解決法 |
|--------|------|--------|
| 4109 | 自動売買未許可 | 設定で許可する |
| 130 | ストップ無効 | StopLoss拡大 |
| 134 | 証拠金不足 | ロット減らす |
