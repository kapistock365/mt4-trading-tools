# FX 5分足スキャルピング - セットアップ詳細説明書

## 📚 概要
本書はボブ・ボルマン著「FX 5分足スキャルピング」で解説されている手法を体系的に整理し、EA（Expert Advisor）として実装するための技術仕様書です。

## 🎯 トレード哲学と基本原則

### コアコンセプト
- **プライスアクション重視**: インジケーターは最小限（25EMAのみ）
- **リスク管理優先**: 小さな損切り（10pips）で資金を守る
- **高頻度トレード**: 5分足での素早いエントリー/エグジット
- **確率的アプローチ**: 個々のトレードより全体の期待値を重視

### 3つの必須条件
1. **支配的圧力の方向**: 全体的なトレンドと同じ方向
2. **ビルドアップの存在**: エントリー前の価格圧縮
3. **適切なブレイク**: ダマシやティーズではない明確な突破

## 📊 主要セットアップ詳細

### 1. パターンブレイク（Pattern Break / PB）

#### 概要
最も基本的なブレイクアウト手法。レンジや三角保ち合いなどのパターンから価格がブレイクする瞬間を捉える。

#### エントリー条件
```
必須条件:
1. 明確な境界線（水平線または斜線）の存在
2. ビルドアップ（最低3-5本の圧縮された足）
3. ブレイク足の実体が境界線を2pips以上超える
4. 25EMAとの位置関係が適切（離れすぎていない）

追加フィルター:
- 時間帯: ロンドン/NY時間優先
- スプレッド: 2pips以下
- ボラティリティ: ATR(14) > 5pips
```

#### ビルドアップの識別
```
定義: 価格が狭いレンジで圧縮される状態

判定基準:
- 連続する3-5本の足
- 各足の高値安値幅が前の足の50-150%以内
- 全体のレンジが10pips以内
- 理想的には短小線の連続
```

#### エグジット戦略
```
利益確定:
- 基本: 20pips固定（リスクリワード比1:2）
- 応用: トレーリングストップ（10pips利益後、5pips幅）

損切り:
- 基本: エントリーから10pips
- 調整: ビルドアップの下限-2pips（最大13pips）
```

#### 具体例
```
EUR/USD 5分足
1. 1.1000で水平レジスタンス形成（3回テスト）
2. 足10-14でビルドアップ形成（5pipsレンジ）
3. 足15で1.1002を実体でブレイク
4. エントリー: 1.1003（ブレイク確認後）
5. 損切り: 1.0993（-10pips）
6. 利確: 1.1023（+20pips）
```

### 2. パターンブレイクプルバック（Pattern Break Pullback / PBPB）

#### 概要
初回ブレイク後の押し目/戻りを待ってエントリーする、より保守的な手法。

#### エントリー条件
```
必須条件:
1. 明確な初回ブレイクの完了
2. ブレイクしたレベルへのプルバック（リテスト）
3. プルバックの反転シグナル
   - ピンバー
   - はらみ足のブレイク
   - ダブルボトム/トップ
4. 25EMAがサポート/レジスタンスとして機能

タイミング:
- 初回ブレイクから5-15本以内
- プルバックが38.2-61.8%フィボナッチレベル
```

#### プルバック反転の識別
```
強いシグナル:
1. ブレイクしたレベルでの明確な反発
2. 25EMAでのサポート/レジスタンス
3. 切りの良い数字（00、50）での反転

弱いシグナル（見送り）:
1. プルバックが深すぎる（>70%）
2. 反転に勢いがない（小さな足）
3. ビルドアップなしの急反転
```

#### リスク管理
```
エントリー価格の決定:
- 反転確認足の高値/安値ブレイク
- スプレッド考慮（+1pip）

損切り設定:
- プルバックの極値から2pips
- 最大12pips（通常より少し広め）

利益目標:
- 初回ブレイクの値幅と同等
- 最低でも損切りの1.5倍
```

### 3. パターンブレイクコンビ（Pattern Break Combo / PBC）

#### 概要
複数のセットアップが重なる最強シグナル。高い勝率が期待できる。

#### エントリー条件
```
以下の2つ以上が同時発生:
1. パターンブレイク + プルバック完了
2. ダブルの圧力（2つの要因が同じ方向）
3. 反転足 + はらみ足の組み合わせ
4. 重要な時間帯の開始（ロンドン/NYオープン）

ダブルの圧力の例:
- トレンド方向 + パターンブレイク
- 25EMAサポート + 切りの良い数字
- ダマシのブレイク失敗 + 逆方向へのビルドアップ
```

#### コンビネーションパターン
```
パターン1: 失敗ブレイクからの逆襲
1. 下方向へのダマシのブレイク
2. 即座に回復して元のレンジへ
3. 上方向へのビルドアップ形成
4. 上方向へのブレイク

パターン2: トリプルサポート
1. 水平サポート
2. 25EMA
3. 切りの良い数字（1.1000等）
→ 3つが重なる地点からの反発

パターン3: 時間帯シンクロ
1. アジア時間のレンジ形成
2. ロンドンオープンでのビルドアップ
3. オープン30分以内のブレイク
```

## 🔧 テクニカル要素の詳細定義

### ダマシのブレイク（False Break）
```
定義: 一時的にレベルを超えるが、すぐに戻る動き

識別方法:
- ブレイク後2-3本以内に元のレベルに戻る
- ブレイクした足の次の足が逆方向
- 出来高が伴わない（MT4では判断困難）

対処法:
- ブレイク後2本待ってエントリー
- ブレイク足の実体で判断（ヒゲは無視）
```

### ティーズブレイク（Tease Break）
```
定義: わずかにレベルを超える様子見の動き

識別方法:
- 1-2pipsの小さなブレイク
- 短小線でのブレイク
- ビルドアップが不完全

対処法:
- 見送りが基本
- 次のより明確なブレイクを待つ
```

### ビルドアップ（Buildup）
```
定義: ブレイク前の価格圧縮・エネルギー蓄積

良いビルドアップ:
- 5本以上の圧縮
- 徐々に値幅が狭くなる
- 短小線の増加
- 三角形やフラグ形成

悪いビルドアップ:
- 2-3本の短い圧縮
- 大きな足が混在
- 方向感がない
```

### 25EMA（指数移動平均線）
```
役割:
1. トレンド方向の確認
2. 動的サポート/レジスタンス
3. プルバックの目標
4. エントリーフィルター

使用方法:
- 価格が上: ロングのみ考慮
- 価格が下: ショートのみ考慮
- タッチ: 反発の可能性
- 乖離大: エントリー見送り
```

### 切りの良い数字（Round Numbers）
```
定義: 00、50で終わる価格（例: 1.1000, 1.1050）

心理的影響:
- 多くの注文が集中
- サポート/レジスタンスとして機能
- ブレイクには追加エネルギー必要

トレード利用:
- ターゲットは手前で設定（1.0998等）
- ブレイク後の再テストを狙う
- 逆張りは避ける
```

## 📈 エントリー/エグジット フローチャート

### エントリー判定フロー
```
1. 環境認識
   ├─ トレンド確認（25EMA）
   ├─ 時間帯チェック
   └─ ボラティリティ確認
   
2. セットアップ識別
   ├─ パターン認識（レンジ、三角、etc）
   ├─ ビルドアップ確認
   └─ ブレイクポイント特定
   
3. エントリートリガー
   ├─ ブレイク確認（2pips以上）
   ├─ ダマシチェック（2本待機）
   └─ 注文執行

4. ポジション管理
   ├─ 損切り設定（即座）
   ├─ 利確設定（即座）
   └─ トレーリング開始（10pips後）
```

### エグジット判定フロー
```
1. 通常エグジット
   ├─ 利確到達: +20pips
   └─ 損切り到達: -10pips
   
2. 早期エグジット（裁量）
   ├─ 逆シグナル発生
   ├─ サポート/レジスタンス到達
   └─ 時間切れ（2時間ルール）
   
3. トレーリングストップ
   ├─ 発動: +10pips到達後
   ├─ 追従: 5pips幅維持
   └─ 確定: 逆行5pipsで決済
```

## 🚫 トレード回避条件

### 絶対に避けるべき状況
1. **重要指標発表前後30分**
2. **スプレッド3pips以上**
3. **金曜NY時間後半**
4. **月曜アジア時間序盤**
5. **ビルドアップなしのブレイク**

### 注意が必要な状況
1. **25EMAから15pips以上乖離**
2. **直近に大きなギャップ**
3. **ボラティリティ異常（ATR<3 or >15）**
4. **連続損失後（3連敗後は休憩）**
