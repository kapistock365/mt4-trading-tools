# FX5MinScalpingIndicator 使用ガイド

## 📌 概要
FX5MinScalpingIndicatorは、ボブ・ボルマンの5分足スキャルピング手法を裁量トレード向けに可視化したインジケーターです。自動売買ではなく、トレーダーの判断を支援する予測型ツールとして設計されています。

## 🎯 設計思想
- **予測型表示**: 「次に何が起きるか」を事前に表示
- **カーブフィッティング回避**: パラメータの過度な最適化を避け、実績あるロジックをそのまま使用
- **裁量判断の支援**: 最終判断は人間が行う前提で、準備時間を提供

## 📊 主要機能

### 1. ビジュアル表示
- **レンジボックス（グレー）**: サポート/レジスタンスレベル
- **ビルドアップゾーン（黄色）**: エネルギー蓄積エリア
- **予測エントリーライン（青/赤点線）**: 次のエントリーポイント
- **SL/TPライン**: リスクリワード比の可視化

### 2. 情報パネル
```
=== FX 5分足スキャルピング ===
パターン: 検出中
レンジ: 1.16300 - 1.16400 (10.0 pips)
ビルドアップ: 6バー 4.3pips (品質70%)

【次のアクション】
↑ 1.16405で買い
↓ 1.16295で売り

【推奨設定】
ロット: 0.02 (リスク2.0%)
R/R比: 1:2.0
```

### 3. アラート機能
- エントリーポイント接近時の通知
- 設定可能なアラート距離

## 🔧 パラメータ設定

### ビルドアップ検出
| パラメータ | デフォルト値 | 説明 |
|-----------|------------|------|
| MinBuildupBars | 3 | 最小ビルドアップバー数 |
| MaxBuildupBars | 10 | 最大ビルドアップバー数 |
| BuildupRangePips | 10.0 | ビルドアップ最大幅（pips） |

### ブレイクアウト設定
| パラメータ | デフォルト値 | 説明 |
|-----------|------------|------|
| BreakoutMinPips | 0.5 | ブレイク最小幅（pips） |
| BreakoutMaxPips | 5.0 | ブレイク最大幅（pips） |

### トレード設定
| パラメータ | デフォルト値 | 説明 |
|-----------|------------|------|
| StopLossPips | 10.0 | 損切り（pips） |
| TakeProfitPips | 20.0 | 利確（pips） |
| RiskPercent | 2.0 | リスク率（%） |

### 表示設定
| パラメータ | デフォルト値 | 説明 |
|-----------|------------|------|
| ShowInfoPanel | true | 情報パネル表示 |
| EnableAlerts | true | アラート有効 |
| AlertDistancePips | 2 | アラート発動距離（pips） |

## 📈 使用方法

### 1. インジケーターの適用
```
1. MT4でチャートを開く（EUR/USD M5推奨）
2. ナビゲーターからFX5MinScalpingIndicatorをチャートにドラッグ
3. パラメータを確認してOK
```

### 2. トレードの流れ
```
1. パターン検出を待つ
   ↓
2. ビルドアップゾーンの確認
   ↓
3. 予測ラインで次のアクションを確認
   ↓
4. アラートまたは視覚的に接近を確認
   ↓
5. 裁量でエントリー判断
```

### 3. 判断のポイント
- **品質スコア**: 70%以上が望ましい
- **ビルドアップ**: 境界に近いほど良い
- **市場環境**: ニュース等を考慮

## ⚠️ 注意事項

### やってはいけないこと
- ✖ パラメータの過度な最適化
- ✖ アラートだけでの機械的エントリー
- ✖ リスク管理の無視

### 推奨事項
- ✓ デモ口座での練習
- ✓ 市場環境の確認
- ✓ 資金管理の徹底

## 🐛 トラブルシューティング

### 表示されない場合
1. インジケーターリストを確認
2. エキスパートアドバイザーが有効か確認
3. DLL許可の設定確認

### アラートが鳴らない場合
1. EnableAlertsパラメータ確認
2. MT4のアラート設定確認
3. AlertDistancePipsの調整

## 📊 パフォーマンス指標

### 推奨環境
- 通貨ペア: EUR/USD, GBP/USD
- 時間足: M5（5分足）
- セッション: ロンドン、ニューヨーク

### 期待される結果
- 1日あたりのシグナル: 3-10回
- 推奨R/R比: 1:2以上
- 品質スコア目標: 70%以上
