## はじめに

### 📌 このEAについて
このEAは、ボブ・ボルマン著「FX 5分足スキャルピング」の手法を自動化したものです。価格アクション（プライスアクション）に基づいて、5分足チャートで短期トレードを行います。

### ✨ 主な特徴
- **3つのトレード戦略**: パターンブレイク、プルバック、コンボ
- **自動リスク管理**: 損切り・利確の自動設定
- **マーケットフィルター**: 時間帯とスプレッドの最適化
- **視覚的サポート**: チャート上にシグナルと情報を表示

### 🎯 推奨環境
- **通貨ペア**: EUR/USD, GBP/USD（低スプレッドペア）
- **時間足**: M5（5分足）専用
- **最小証拠金**: $1,000（0.01ロット運用時）
- **推奨証拠金**: $5,000以上

## トレード戦略解説

### 🔵 戦略1: パターンブレイク（Pattern Break）

#### 概要
レンジ相場からのブレイクアウトを狙う基本戦略です。

#### チャートパターン
```
価格推移イメージ：
    ↑
    │     ←─ ブレイクアウト（エントリー）
    │   ┌─────┐
    │   │ビルド │  ← 3-10本の横ばい（ビルドアップ）
    │   │アップ │
    │   └─────┘
    │
    └─────────────→ 時間
```

#### エントリー条件
1. **ビルドアップ形成**: 3-10本のローソク足が狭いレンジ（10pips以内）で推移
2. **ブレイクアウト確認**: レンジを2pips以上ブレイク
3. **モメンタム確認**: ブレイク方向に勢いがある

#### 実際のトレード例
```
10:00 - レンジ形成開始（1.1000-1.1010）
10:30 - ビルドアップ完成（6本のローソク足）
10:35 - 上方ブレイク（1.1012突破）
10:35 - 買いエントリー: 1.1012
      - 損切り: 1.1002（-10pips）
      - 利確: 1.1032（+20pips）
11:00 - 利確到達
```

---

### 🟢 戦略2: パターンブレイク・プルバック（PB Pullback）

#### 概要
ブレイクアウト後の一時的な戻り（プルバック）を待ってエントリーする、より安全性の高い戦略です。

#### チャートパターン
```
価格推移イメージ：
    ↑
    │         ╱─── 第2波動（エントリー）
    │      ╱─╲╱
    │    ╱   ╲ ← プルバック（38.2-61.8%）
    │  ╱     
    │ ╱ ←─ 初回ブレイク
    ├─────┐
    │ビルド│
    └─────┘
    └─────────────→ 時間
```

#### エントリー条件
1. **初回ブレイクアウト**: パターンブレイクが発生
2. **プルバック待機**: 価格が38.2%-78.6%（フィボナッチ）まで戻る
3. **反転確認**: サポート/レジスタンスで反発
4. **エントリー**: 反転確認後にブレイク方向へエントリー

#### 実際のトレード例
```
14:00 - ビルドアップ形成（1.1050-1.1060）
14:20 - 上方ブレイク（1.1065到達）
14:30 - プルバック開始
14:40 - 50%戻し（1.1057）でサポート確認
14:45 - 買いエントリー: 1.1058
      - 損切り: 1.1048（-10pips）
      - 利確: 1.1078（+20pips）
15:20 - 利確到達
```

---

### 🔴 戦略3: パターンブレイク・コンボ（PB Combo）

#### 概要
2つのビルドアップが連続して形成される強力なパターンです。

#### チャートパターン
```
価格推移イメージ：
    ↑
    │              ╱── 最終ブレイク（エントリー）
    │          ┌──┐╱
    │          │B2│ ← 第2ビルドアップ
    │      ╱───┴──┘
    │    ╱ 
    │  ┌──┐╱ ← 第1ブレイク
    │  │B1│  ← 第1ビルドアップ
    └──┴──┴────────→ 時間
```

#### エントリー条件
1. **第1ビルドアップ**: 3-10本でレンジ形成
2. **第1ブレイク**: レンジをブレイクアウト
3. **第2ビルドアップ**: ブレイク後、再度レンジ形成（2-8本）
4. **最終ブレイク**: 第2ビルドアップを同方向にブレイク

#### 実際のトレード例
```
09:00 - 第1ビルドアップ形成（1.1100-1.1108）
09:25 - 上方ブレイク（1.1110）
09:35 - 第2ビルドアップ形成開始（1.1108-1.1113）
09:50 - 第2ビルドアップ完成（5本）
09:55 - 上方ブレイク（1.1115）
09:55 - 買いエントリー: 1.1115
      - 損切り: 1.1105（-10pips）
      - 利確: 1.1135（+20pips）
10:30 - 利確到達
```

## インストール方法

### 📁 ステップ1: ファイルの配置

1. **MT4のデータフォルダを開く**
   - MT4を起動
   - メニュー: ファイル → データフォルダを開く

2. **ファイルをコピー**
```
MT4データフォルダ/
├── MQL4/
│   ├── Experts/
│   │   └── FX5MinScalpingEA.mq4（ここに配置）
│   └── Include/
│       └── FX5MinScalping/（フォルダごとコピー）
│           ├── DataStructures.mqh
│           ├── MarketAnalyzer.mqh
│           ├── BuildupDetector.mqh
│           ├── PatternBreakPlugin.mqh
│           ├── PBPullbackPlugin.mqh
│           ├── PBComboPlugin.mqh
│           ├── TimeFilter.mqh
│           └── SpreadFilter.mqh
```

### 🔧 ステップ2: コンパイル

1. **MetaEditorを開く**（MT4でF4キー）
2. **FX5MinScalpingEA.mq4を開く**
3. **コンパイル**（F7キー）
4. エラーがないことを確認

### ▶️ ステップ3: EAの適用

1. **5分足チャートを開く**（EUR/USD推奨）
2. **EAをドラッグ&ドロップ**
3. **設定画面で「自動売買を許可」にチェック**
4. **OKをクリック**

## 運用ガイドライン

### 📅 推奨取引時間帯

#### ベストタイム（最も推奨）
- **21:00-01:00 JST**: ロンドン・NYオーバーラップ
  - 最高の流動性
  - 明確なトレンド
  - 狭いスプレッド

#### グッドタイム（推奨）
- **16:00-18:00 JST**: ロンドンオープン
  - 高ボラティリティ
  - ブレイクアウト多発

- **22:00-24:00 JST**: NY中盤
  - 安定したトレンド
  - 適度なボラティリティ

#### 避けるべき時間
- **06:00-08:00 JST**: アジア深夜
- **重要指標発表前後30分**
- **月曜早朝・金曜深夜**

### 📈 段階的な運用開始

#### Phase 1: デモ口座（2-4週間）
1. 最小ロット（0.01）で開始
2. 1日の結果を記録
3. 勝率50%以上を確認

#### Phase 2: リアル口座・最小リスク（1ヶ月）
1. 証拠金の0.5-1%リスク
2. 1日2-3トレードに制限
3. 週次でパフォーマンス評価

#### Phase 3: 通常運用
1. リスクを1-2%に引き上げ
2. 複数戦略を有効化
3. パラメータの微調整

### 🎯 パフォーマンス目標

| 期間 | 目標 | 最低基準 |
|------|------|----------|
| 日次 | +0.5-1% | -2%以内 |
| 週次 | +2-5% | ±0% |
| 月次 | +5-10% | +2% |
| 最大DD | 10%以内 | 15%で停止 |

## トラブルシューティング

### ❌ よくある問題と解決法

#### 問題: トレードが実行されない
**確認事項:**
1. 自動売買ボタンがONか確認（ニコちゃんマーク）
2. エキスパートタブでエラーメッセージを確認
3. 時間フィルターの設定を確認
4. スプレッドが条件内か確認

**解決策:**
```
// ターミナルでチェック
- スプレッド: 2.0pips以下か？
- 時間: 取引時間内か？
- 証拠金: 十分か？
```

#### 問題: エラー4109（Trade not allowed）
**解決:**
1. EAプロパティで「自動売買を許可」にチェック
2. MT4の自動売買を有効化
3. ブローカーがEA取引を許可しているか確認

#### 問題: エラー130（Invalid stops）
**解決:**
1. ストップレベルを確認
```
最小ストップ = MarketInfo(Symbol(), MODE_STOPLEVEL)
```
2. StopLossPipsを最小ストップ以上に設定

#### 問題: 頻繁な損切り
**調整方法:**
1. StopLossPipsを12-15に拡大
2. BreakoutMinPipsを3.0に増加
3. MinBuildupBarsを4-5に増加

### 📊 パフォーマンス診断

#### 勝率が低い場合（40%以下）
- BuildupRangePipsを8.0に縮小
- ConfirmationBarsを3に増加
- 時間帯を絞る（21:00-24:00のみ）

#### 取引回数が少ない場合（週5回以下）
- MinBuildupBarsを3に減少
- BreakoutMinPipsを1.5に減少
- 複数戦略を有効化

#### ドローダウンが大きい場合（10%超）
- RiskPercentを1%に減少
- MaxTradesPerDayを3に制限
- UseBreakEvenをtrueに設定

## リスク管理

### ⚠️ 重要な注意事項

#### 資金管理の鉄則
1. **証拠金の2%ルール**: 1トレードのリスクは証拠金の2%以内
2. **日次5%ルール**: 1日の最大損失は5%で取引停止
3. **分散投資**: 全資金をFXに投入しない

#### リスク計算例
```
証拠金: $5,000
1トレードリスク: 2% = $100
ロット計算:
- 10pips損切り = 0.1ロット
- 20pips損切り = 0.05ロット
```

### 🛡️ 安全装置の活用

| 機能 | 説明 | 設定方法 |
|------|------|----------|
| MaxDailyLoss | 日次損失制限 | 3-5%推奨 |
| MaxTradesPerDay | 取引回数制限 | 3-5回推奨 |
| UseBreakEven | 損益分岐点移動 | true推奨 |
| CooldownMinutes | クールダウン時間 | 30分推奨 |

### 📉 ドローダウン対策

#### 10%ドローダウン時
1. ロットサイズを半分に
2. 1日1トレードに制限
3. 勝率の高い時間帯のみ

#### 15%ドローダウン時
1. 一時的に取引停止（1週間）
2. パラメータ見直し
3. デモ口座で再検証

#### 20%ドローダウン時
1. EA使用停止
2. 戦略の根本的見直し
3. 追加資金投入は厳禁
